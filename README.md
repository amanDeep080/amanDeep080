```
                 ┌────────────────────┐

                 └─────────┬──────────┘
                            │  HTTPS / REST / GraphQL
                 ┌─────────▼──────────┐
                 │    API Gateway       │
                 │  (Auth · Rate Limit) │
                 └─────────┬──────────┘
              ┌─────────────┼─────────────┐
     ┌────────▼──────┐ ┌────▼───────┐ ┌────▼────────┐
     │  Auth Service  │ │ Core Domain │ │ Notification │
     │ (Spring Boot)  │ │  Services   │ │   Service    │
     └────────┬──────┘ └────┬───────┘ └────┬────────┘
              │              │               │
```
